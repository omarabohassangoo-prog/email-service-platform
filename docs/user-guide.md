# دليل المستخدم - خدمة البريد الإلكتروني المتكاملة (ESP Platform)

## 1. المقدمة
تعتبر منصة خدمة البريد الإلكتروني (ESP Platform) حلاً مؤسسياً مركزياً متكاملاً لإدارة وإرسال الحملات البريدية، الإشعارات الفورية، وتتبع تسليم الرسائل عبر واجهات برمجة التطبيقات (API) ولوحة تحكم متطورة للمسؤولين.

---

## 2. لوحة التحكم (Dashboard)
تتيح لوحة التحكم للمستخدمين والمشرفين متابعة:
- إحصاییات الإرسال اللحظية (المرسلة، الناجحة، الفاشلة، ومعدل الفتح/النقر).
- حالة طوابير الانتظار (Queue Monitor) ومعالجة المهام.
- إدارة قوالب البريد الإلكتروني (Template Manager) بتصميم مرن.
- إدارة مفاتيح الـ API وصلاحيات الوصول.

---

## 3. إرسال البريد الإلكتروني
- **الإرسال الفردي أو الجماعي:** من خلال واجهة الاستخدام المباشرة أو عبر استدعاء نقطة النهاية `/api/v1/email/send`.
- **المرفقات:** يدعم النظام إرفاق الملفات عبر Vercel Blob بتشفير وأمان عاليين.
- **التخصيص:** استخدام متغيرات ديناميكية داخل قوالب البريد.

---

## 4. الأسئلة الشائعة (FAQ)
- **كيف يمكنني الحصول على مفتاح API؟**
  يمكنك الانتقال إلى قسم إدارة مفاتيح API في لوحة التحكم وتوليد مفتاح جديد برتبة صلاحيات محددة.
- **كيف يتم ضمان وصول البريد إلى صندوق الوارد (Inbox) في Gmail و Outlook؟**
  يتم تكوين سجلات `SPF`, `DKIM`, و `DMARC` تلقائياً عبر النطاق المخصص مع مراقبة السمعة عبر Google Postmaster.
