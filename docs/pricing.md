# تسعير وباقات منصة البريد الإلكتروني (ESP Platform Pricing)

تتطابق خطط الأسعار لدينا مع احتياجات المطورين، الشركات الناشئة، والمؤسسات الكبرى لضمان أقصى مرونة وأداء عالي.

---

## 1. باقة المطورين (Developer Tier)
- **السعر:** مجاناً (مفتوحة المصدر برخصة MIT)
- **المميزات:**
  - استخدام كامل للكود المصدري عبر GitHub.
  - دعم حتى 10,000 إرسال بريدي شهرياً (عند الاستضافة الذاتية).
  - واجهات API أساسية ومكتبات SDK.
  - مجتمع دعم عبر GitHub Discussions.

---

## 2. باقة الشركات الناشئة (Startup / Pro Tier)
- **السعر:** **$49 / شهرياً** (أو $470 سنوياً - توفير 20%)
- **المميزات:**
  - إرسال حتى 250,000 بريد إلكتروني شهرياً.
  - نظام طوابير عالي الأداء (Redis / BullMQ).
  - قوالب بريد غير محدودة مع محرر مرن.
  - دعم فني عبر البريد الإلكتروني (وقت استجابة < 24 ساعة).
  - مراقبة السمعة عبر Google Postmaster.

---

## 3. باقة المؤسسات والشركات الكبرى (Enterprise Tier)
- **السعر:** **$199 / شهرياً** (أو $1,900 سنوياً)
- **المميزات:**
  - إرسال غير محدود (حسب الموفرين المربوطين مثل AWS SES, SendGrid).
  - نطاقات إرسال متعددة مع مصادقة كاملة (SPF, DKIM, DMARC).
  - دعم فني مخصص على مدار الساعة (24/7 Dedicated Support & SLA).
  - حماية متقدمة ضد الاحتيال وسجلات تدقيق موسعة (Audit Logs).
  - نشر مخصص على Vercel Pro أو السحابة الخاصة (VPC / On-Premise).

---

## 4. باقة مخصصة (Custom / On-Premise)
- **السعر:** حسب الطلب (Contact Sales)
  - للمؤسسات الحكومية والمالية الكبرى التي تتطلب استضافة محلية بالكامل (On-Premise) مع توافقية صارمة مع معايير الأمان العالمية (GDPR, HIPAA, SOC2).
